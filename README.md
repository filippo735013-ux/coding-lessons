# 🚀 Lezioni di Coding & File Lab / Coding Lessons & File Lab

### 🇮🇹 Descrizione del Progetto
Benvenuto! Questa repository è una guida pratica per principianti che vogliono iniziare a programmare da zero. Include concetti fondamentali, basi di diversi linguaggi, applicazioni matematiche e progetti divertenti (come piccoli scherzi informatici). 

Il progetto è strutturato con guide teoriche in PDF ed esercizi pratici basati sulla modifica dei file.

### 🇬🇧 Project Description
Welcome! This repository is a practical guide for beginners looking to start coding from scratch. It includes fundamental concepts, basics of different programming languages, mathematical applications, and fun projects (like minor coding pranks).

The project is structured with theoretical PDF guides and practical exercises based on file modification.

---

## 📂 Struttura della Repository / Repository Structure

### 📕 1. Cartella `test/` (Guide PDF)
Contiene **3 file PDF** che spiegano come iniziare da zero / Contains **3 PDF files** explaining how to start from scratch:
* **Python:** Le basi del linguaggio e la sua logica. / *Language basics and logic.*
* **C# & C++:** Introduzione alla programmazione e alla sintassi. / *Introduction to programming and syntax.*
* **Extra:** Applicazioni di matematica e guide creative (inclusi trucchi e scherzi di coding). / *Math applications and creative guides (including programming pranks).*

### 📄 2. Esercizi Pratici / Practical Exercises
Ci sono **5 file `.txt` vuoti** pronti per essere modificati. Usali per fare pratica con la scrittura, la lettura e la manipolazione dei file attraverso il codice. / *There are **5 empty `.txt` files** ready to be modified. Use them to practice file writing, reading, and manipulation through code.*

---

## 🛠️ Come Iniziare / How to Get Started

1. **🇮🇹 Leggi i PDF:** Apri la cartella `test/` e leggi le guide per comprendere le basi.
2. **🇬🇧 Read the PDFs:** Open the `test/` folder and read the guides to understand the basics.

3. **🇮🇹 Fai pratica:** Usa i 5 file `.txt` per testare i tuoi script in Python, C# o C++.
4. **🇬🇧 Practice:** Use the 5 `.txt` files to test your Python, C#, or C++ scripts.
